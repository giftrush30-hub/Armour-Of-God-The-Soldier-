# ARMOUR OF GOD: THE SOLDIER

A mobile-friendly, biblical-inspired 2D fighting game prototype. Choose a warrior, battle Fear at the mountain's edge, earn coins and armour, and explore the Scripture Vault.

## Run locally

Open `index.html` in a modern browser. This is a static HTML/CSS/JavaScript project and requires no build step.

## Deploy to Vercel

Import this GitHub repository into Vercel. Choose **Other** as the framework preset, leave build and install commands empty, and deploy from the repository root.

## Current prototype limits

- Progress is saved in the current browser when local storage is available.
- Premium characters and shop purchases are previews only.
- No live payment provider is connected; no purchases are charged.
- This is an early prototype, not a finished commercial game.
